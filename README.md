# CET-6 Translation Lab

在线地址：https://kakuutetetsu.github.io/cet6-translation-lab/

静态六级翻译练习室，涵盖 2023 年 6 月至 2026 年 6 月的 21 套材料，共 110 道练习、143 个英文句子的逐句拆解。

新增 99 道题的中英文逐字取自用户提供的《精翻 - 副本.docx》。参考译文是学习材料中的适度精准翻译版，并非官方标准答案。原有 11 道题及其 17 句拆解保持不变。

## 功能

- 中文翻译、答案对照及差异提示
- 短语和单词两种词块拼句
- 按套题闯关、总览套题筛选及收藏
- 全部题目的逐句拆解：主干、修饰、词汇、分段与语序、翻译理由
- 首页独立拆解入口；检查答案或查看参考答案后，拆解按钮位于参考译文上方
- 错题重练、学习记录、草稿恢复与深浅色主题
- 响应式布局，支持手机和电脑

## 本地运行与发布

运行 `node serve.mjs`，访问 http://127.0.0.1:4173/。

GitHub Pages 使用 `main` 分支根目录发布，无构建依赖，无后端，无在线 AI 接口。题库保存在 `questions.js`，套题目录保存在 `sets.js`。

学习记录使用原有 `cet6-translation-lab-v1` localStorage 键；新增题目不会清除旧记录。记录仅保存在当前浏览器，不自动跨设备同步。
