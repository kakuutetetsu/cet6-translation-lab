# CET-6 Translation Lab

六级翻译主动回忆训练室。独立静态项目，使用 HTML、CSS、原生 JavaScript 与 localStorage。

## 文件结构

```text
cet6-translation-lab/
├── index.html       页面入口
├── style.css        响应式布局与深浅色主题
├── questions.js     11 道题的中文原文和英文参考译文
├── core.js          自动分块、随机排列、标准化与词语差异算法
├── app.js           训练流程、提示、自评与本地保存
├── serve.mjs        可选的本地预览服务，使用 Node.js 内置模块
├── .nojekyll        GitHub Pages 静态发布标记
└── README.md        运行、部署与验收说明
```

## 运行

解压后可直接用浏览器打开 `index.html`。题库通过本地脚本加载。

推荐通过固定的 HTTP 地址练习，以获得稳定的浏览器存储来源。在已安装 Node.js 的电脑上，进入项目文件夹运行以下命令，无需安装依赖。

```sh
node serve.mjs
```

打开 <http://127.0.0.1:4173>，按 Ctrl+C 停止服务。网站部署后只使用静态文件，`serve.mjs` 用于本地预览。

浏览器以来源区分学习记录。直接打开文件、本地 HTTP、GitHub Pages 各自使用独立的记录。固定使用同一浏览器与地址，清除站点数据会清除学习记录。浏览器拒绝保存时，页面会显示提示。

## GitHub Pages 部署

1. 在 GitHub 建立独立仓库，例如 `cet6-translation-lab`。
2. 将本文件夹中的文件上传到仓库 `main` 分支根目录，确保 `index.html` 直接位于根目录。
3. 进入仓库的 **Settings → Pages**。
4. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
5. 选择 **main** 和 **/(root)**，点击 **Save**。
6. 等待仓库的 Pages 部署完成，使用 Pages 设置页显示的网址访问。

所有网页资源采用相对路径，支持 GitHub Pages 的仓库子路径。部署步骤依据 GitHub 官方文档。[GitHub Pages 发布源配置](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

本次交付为本地独立项目，线上部署由上述步骤完成。

## 学习记录与判定

- 首页覆盖率按至少检查过一次的题目计数，掌握数单独统计。
- 中文翻译、整套闯关、错题重练、短语拼句、单词拼句分别保存草稿。刷新恢复当前页面、位置、输入、词块选择、提示和反馈。
- 检查答案计一次练习，同一轮重复点击检查保持次数稳定。重置后再检查会增加次数。
- 选择新一轮训练时，已检查的本模式草稿重置，未完成草稿保留。首页“继续上次练习”恢复完整会话。
- 提示、主动查看译文或检查出差异会加入复习。英文翻译差异供学习者自行判断，独立作答后可自评掌握并移出复习。
- 检查前使用提示或查看译文的作答需要重置后独立尝试，才能标记掌握。检查后修改答案也需要重置才能重新获得独立自评资格。
- 按套题闯关要求每题作答并检查后继续。掌握由自评按钮独立记录。
- 短语由参考译文按标点、连接词和长度自动分组。单词模式按空格拆分，标点随原词保留，正确顺序可逐字还原参考译文。
- 对比忽略大小写、空格与标点。差异高亮使用词序对齐，展示用词或顺序的区别，语义和语法由学习者对照判断。

## 验收结果

- 三套题共 11 道，题数分别为 4、4、3。全部中英文字符串已与用户提供的文本核对。
- 全部 11 道题的两种拆分均可完整拼回原译文，进行了 2,200 次随机排列验证。
- 已检查大小写、空格、标点标准化，以及重复词的差异对齐。
- 已通过浏览器走完三套完整闯关流程。
- 已通过浏览器验证短语与单词拼句、撤回、模式切换、输入保存、刷新恢复、提示、参考译文、重置、自评、收藏、收藏筛选、总览显隐、错题重练与主题保存。
- 已检查桌面和窄屏响应式布局、长中文题目与大输入框。手机验收采用浏览器窄屏模拟，实体手机与其他浏览器内核尚未实测。
- 页面通过本地 HTTP 成功加载，浏览器验收未见应用错误。GitHub Pages 线上发布尚未执行。
